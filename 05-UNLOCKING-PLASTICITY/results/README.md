# Result files

`repeat_previous_easy/` contains fifteen sanitized run summaries, a seed table,
episode returns, and the causal-ablation aggregate.

`repeat_previous_medium/` contains ten sanitized run summaries, paired learning
curves, final CUP structure summaries, and the acquisition aggregate.

`wisconsin/` contains only the control-ladder values reported in the article and
an explicit provenance status.

No file contains a per-decision trace.
